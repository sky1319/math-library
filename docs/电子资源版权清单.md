# 电子资源版权与来源清单

> 清单版本：1.0  
> 核验日期：2026-08-19  
> 适用范围：本项目在线阅读模块

## 1. 使用边界

本模块只展示下表所列古典作品的原文。它不复制馆藏记录所对应的现代纸书版本，也不使用现代出版社的校注、译文、插图、封面、字体或版式。除清单中的 4 部作品外，其余馆藏只提供书目信息，默认不提供全文。

作品原作与数字文本是两个不同的权利层次：古典原作按作者逝世时间和发表时间判断公版状态；中文维基文库参与者整理的数字文本按照页面声明的 CC BY-SA 4.0 使用。因此阅读器必须保留来源、协议链接、署名和修改说明。

## 3. 核验标准

- 作者逝世超过 100 年，且作品在 1930 年前发表，按比通常“作者终生加 50 年”更保守的时间阈值筛选。
- 来源页应将古典原作标示为公有领域，并提供可追溯的章节页。
- 数字文本来源必须明确允许复制和网络传播；本项目按 CC BY-SA 4.0 保留来源、署名、协议链接和修改说明。
- 不采用仅声明“在美国公版”但未说明中国使用条件的来源。
- 不从现代纸书扫描、OCR 或录入正文，不使用第三方封面和插图。
- 来源、许可或内容出现争议时立即将 `ebook_resources.published` 设为 `false`；普通管理接口只支持下架，不支持未经复核重新发布。

## 4. 法律与平台依据

- [中华人民共和国著作权法（国家版权局）](https://www.ncac.gov.cn/xxfb/flfg/flfg_532/202103/t20210309_50530.html)：自然人作品保护期、复制权、信息网络传播权，以及翻译、注释、整理作品的相关规则。
- [信息网络传播权保护条例（中国网信网）](https://www.cac.gov.cn/2013-02/18/c_126468776.htm)：图书馆数字传播例外具有场所、来源和技术措施等限制，不能直接作为公开全文网站的一般授权。
- [中文维基文库版权方针](https://zh.wikisource.org/zh-hans/Wikisource%3A%E7%89%88%E6%9D%83)：站内贡献的许可和公有领域要求。
- [CC BY-SA 4.0 法律文本](https://creativecommons.org/licenses/by-sa/4.0/legalcode.zh-hans)：复制、改编、署名、协议链接、修改说明和相同方式共享条件。

## 5. 风险说明

任何系统都无法对未来法律变化、来源站点错误或权利人争议作“绝对零风险”的法律保证。本项目采用的是技术上可执行的保守标准，并通过白名单、发布闸门、持续署名和快速下架将风险降到可控范围。用于公开商业部署前，运营主体仍应由合格法律专业人士复核本清单，并定期复查来源页和适用法律。

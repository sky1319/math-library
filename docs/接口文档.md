# 智能图书管理系统接口文档

> 文档版本：3.3  
> 对应版本：1.0.0  
> 更新日期：2026-08-19  
> Base URL：`http://localhost:8091`

## 1. 通用约定

- 编码：UTF-8；普通接口使用 `application/json`，流式 Agent 接口使用 `text/event-stream`。
- 除登录、健康检查、OpenAPI 文档外，接口均需携带 JWT：

```http
Authorization: Bearer <access_token>
```

- 前端开发服务器将 `/api` 代理至后端 `8091` 端口。
- 用户身份始终从 JWT 中读取，客户端不得通过请求参数指定其他用户。

### 1.1 统一响应体

```json
{
  "success": true,
  "code": "OK",
  "message": "操作成功",
  "data": {}
}
```

| 字段 | 说明 |
|---|---|
| `success` | 请求是否成功 |
| `code` | 稳定的业务或错误码，供前端分支处理 |
| `message` | 面向用户的提示信息 |
| `data` | 业务数据；失败时通常为 `null` |

### 1.2 HTTP 状态与错误码

| 状态 | 场景 | 示例 code |
|---|---|---|
| `200` | 查询或操作成功 | `OK` |
| `400` | 参数校验失败、非法排序参数 | `VALIDATION_ERROR`、`INVALID_SORT_FIELD` |
| `401` | 未登录、JWT 无效或凭据错误 | `UNAUTHORIZED`、`INVALID_CREDENTIALS` |
| `403` | 已登录但权限不足或权属材料不完整 | `FORBIDDEN`、`EBOOK_RIGHTS_NOT_VERIFIED` |
| `404` | 图书、借阅记录或已核验电子资源不存在 | `BOOK_NOT_FOUND`、`ACTIVE_BORROW_NOT_FOUND`、`EBOOK_NOT_AVAILABLE` |
| `409` | 库存、重复借阅、愿望单重复等冲突 | `BOOK_OUT_OF_STOCK`、`BOOK_ALREADY_BORROWED` |
| `503` | 外部 AI 或正版文本来源不可用 | `SERVICE_UNAVAILABLE`、`EBOOK_SOURCE_UNAVAILABLE` |
| `500` | 未预期服务端错误 | `INTERNAL_ERROR` |

预约、续借和 Agent 确认还会使用：`RESERVATION_DUPLICATE`、`RENEW_LIMIT_REACHED`、`BOOK_HAS_RESERVATION_QUEUE`、`AGENT_ACTION_EXPIRED`、`CATALOG_PROPOSAL_EXPIRED`、`STAFF_ROLE_REQUIRED`、`ADMIN_ROLE_REQUIRED`。彻底删除书目还可能返回 `BOOK_HAS_BORROW_HISTORY`、`BOOK_HAS_RESERVATION_HISTORY`、`BOOK_IN_WISH_LIST` 或 `BOOK_HAS_RELATIONS`。

校验失败示例：

```json
{
  "success": false,
  "code": "VALIDATION_ERROR",
  "message": "请求参数校验失败",
  "data": {
    "title": "书名不能为空"
  }
}
```

## 2. 数据模型

### 2.1 登录请求与响应

```json
// POST /api/auth/login
{ "userId": "<user-id>", "password": "<password>" }
```

| 字段 | 类型 | 说明 |
|---|---|---|
| `token` | String | JWT 访问令牌 |
| `userId` | String | 用户编号 |
| `name` | String | 用户姓名 |
| `role` | String | `USER`、`LIBRARIAN` 或 `ADMIN` |

### 2.2 图书请求 `BookRequest`

| 字段 | 新增 | 更新 | 约束 |
|---|---:|---:|---|
| `isbn` | 必填 | 路径参数为准 | 最长 32 位 |
| `title` | 必填 | 可选 | 最长 255 位 |
| `author` | 必填 | 可选 | 最长 255 位 |
| `publisher` | 可选 | 可选 | 最长 255 位 |
| `category` | 可选 | 可选 | 最长 100 位 |
| `totalCount` | 必填 | 可选 | 非负整数，且不得小于已借数量 |
| `location` | 可选 | 可选 | 最长 100 位 |
| `keywords` | 可选 | 可选 | 最长 500 位 |
| `description` | 可选 | 可选 | 最长 2000 位 |
| `borrowable` | 可选 | 可选 | 是否允许借阅 |

`BookResponse` 在上述图书字段之外，包含 `borrowedCount` 与 `availableCount`（总量减已借量）。

### 2.3 预约、通知和 Agent 操作草案

`ReservationResponse` 字段：`id`、`isbn`、`bookTitle`、`status`、`queuePosition`、`reservedAt`、`notifiedAt`、`expiresAt`。预约状态为 `WAITING`、`NOTIFIED`、`COMPLETED`、`CANCELLED`、`EXPIRED`。

`NotificationResponse` 字段：`id`、`type`、`title`、`content`、`read`、`createdAt`、`readAt`。

`AgentActionDraftResponse` 字段：`token`、`actionType`、`isbn`、`bookTitle`、`summary`、`status`、`expiresAt`、`details`。`details` 保存经服务端校验后的书名、ISBN、数量和原始查询词等参数。草案默认 5 分钟有效，状态为 `PENDING`、`CONFIRMED`、`CANCELLED` 或 `EXPIRED`。

### 2.4 分页返回 `PageResponse<BookResponse>`

```json
{
  "content": [],
  "page": 0,
  "size": 20,
  "totalElements": 100,
  "totalPages": 5,
  "first": true,
  "last": false
}
```

### 2.5 Agent 返回 `AgentRunResponse`

| 字段 | 说明 |
|---|---|
| `answer` | Agent 最终回答 |
| `sessionId` | 会话编号 |
| `toolsUsed` | 本轮实际调用的查询或草案工具 |
| `iterations` | 规划/工具循环次数 |
| `pendingAction` | 可选；本轮生成的待确认操作草案 |
| `catalogProposal` | 可选；馆员/管理员请求馆藏维护时返回的多方案候选集 |
| `navigation` | 可选；Agent 已通过服务端核验后返回的受控页面跳转指令 |

`catalogProposal` 包含 `token`、`expiresAt` 和 `groups`。每个分组对应一个输入书名，包含 `query`、`candidates` 和 `addNewAllowed`；候选项包含书目元数据、总馆藏、已借数量、可借状态以及当前角色允许执行的 `operations`。方案令牌默认 5 分钟有效，只能由创建方案的当前账号使用。

当前唯一允许的 `navigation.type` 是 `OPEN_EBOOK`。它包含 `isbn`、`bookTitle`、`chapterNumber`、`chapterCount` 和 `message`。前端只接受该固定类型并用内部路由打开阅读器，不执行模型生成的 URL。未通过权属或发布闸门时 `navigation` 必须为 `null`。

```json
{
  "navigation": {
    "type": "OPEN_EBOOK",
    "isbn": "4344337503054",
    "bookTitle": "红楼梦",
    "chapterNumber": 10,
    "chapterCount": 120,
    "message": "已核验该书的公版原文与数字文本许可，可以安全进入阅读器"
  }
}
```

## 3. 认证接口

### `POST /api/auth/login`

权限：公开。

请求体见 2.1。`userId`、`password` 均不能为空，最长 64 位。成功时返回登录响应；账号或密码错误时返回 `401 / INVALID_CREDENTIALS`。

## 4. 馆藏查询接口

以下接口需要任意已登录角色。

| 方法 | 路径 | 说明 |
|---|---|---|
| `GET` | `/api/books` | 获取全部图书 |
| `GET` | `/api/books/search?keyword=` | 按书名、作者、关键词搜索；关键字可空 |
| `GET` | `/api/books/page?keyword=&page=0&size=20&sortBy=title&direction=asc` | 服务端分页、搜索与排序 |
| `GET` | `/api/books/{isbn}` | 获取图书详情 |

分页参数：`page >= 0`，`1 <= size <= 100`；`sortBy` 仅支持 `title`、`author`、`category`、`totalCount`、`borrowedCount`；`direction` 为 `asc` 或 `desc`。

## 5. 读者接口

以下接口需要登录；用户仅能操作自己的数据。

| 方法 | 路径 | 说明 |
|---|---|---|
| `GET` | `/api/user/books/search?keyword=` | 图书搜索兼容入口 |
| `GET` | `/api/user/books/{isbn}` | 图书详情兼容入口 |
| `GET` | `/api/user/books/{isbn}/similar` | 获取相似图书 |
| `POST` | `/api/user/borrow/{isbn}` | 借阅图书 |
| `POST` | `/api/user/return/{isbn}` | 归还图书 |
| `POST` | `/api/user/renew/{isbn}` | 续借图书；默认每条借阅记录最多续借 1 次 |
| `GET` | `/api/user/borrow-records` | 当前用户借阅记录 |
| `GET` | `/api/user/wish-list` | 当前用户愿望单 |
| `POST` | `/api/user/wish-list/{isbn}` | 加入愿望单 |
| `DELETE` | `/api/user/wish-list/{isbn}` | 移出愿望单 |
| `GET` | `/api/user/reservations` | 当前用户预约记录 |
| `POST` | `/api/user/reservations/{isbn}` | 无库存时加入预约队列 |
| `DELETE` | `/api/user/reservations/{reservationId}` | 取消自己的有效预约 |
| `GET` | `/api/user/notifications` | 当前用户站内通知 |
| `GET` | `/api/user/notifications/unread-count` | 未读通知数量 |
| `PUT` | `/api/user/notifications/{notificationId}/read` | 标记单条通知已读 |
| `PUT` | `/api/user/notifications/read-all` | 全部通知已读 |

借阅规则：默认最多同时借阅 5 本，最长借期 30 天；图书须允许借阅且存在库存；同一用户不可重复借阅同一本未归还图书。借阅与归还使用事务、用户悲观锁和库存条件更新，发生库存竞争时返回 `409`，不会产生超借。续借要求未逾期且未达到次数上限；存在其他读者预约时不能续借。无库存图书可以排队预约，归还后系统按队列顺序通知下一位读者。

## 6. 管理员接口

馆藏新增、修改、借阅记录、统计和日志接口需 `ADMIN` 或 `LIBRARIAN`；用户账号管理和彻底删除书目仅需 `ADMIN`。

| 方法 | 路径 | 说明 |
|---|---|---|
| `GET` | `/api/admin/books` | 获取全部馆藏 |
| `GET` | `/api/admin/books/{isbn}` | 获取馆藏详情 |
| `POST` | `/api/admin/books` | 新增图书，使用 `BookRequest` |
| `PUT` | `/api/admin/books/{isbn}` | 更新图书 |
| `DELETE` | `/api/admin/books/{isbn}` | 彻底删除书目，仅管理员；存在任何业务引用时拒绝 |
| `GET` | `/api/admin/borrow-records` | 全部借阅记录 |
| `GET` | `/api/admin/borrow-records/user/{userId}` | 指定用户借阅记录 |
| `GET` | `/api/admin/borrow-records/book/{isbn}` | 指定图书借阅记录 |
| `GET` | `/api/admin/overdue-warnings` | 逾期记录 |
| `GET` | `/api/admin/statistics/categories` | 分类借阅统计 |
| `GET` | `/api/admin/logs` | 审计日志 |
| `GET` | `/api/admin/users` | 用户列表，仅管理员 |
| `POST` | `/api/admin/users` | 创建读者、馆员或管理员，仅管理员 |
| `PUT` | `/api/admin/users/{userId}` | 修改姓名、角色、联系方式和启停状态，仅管理员 |
| `POST` | `/api/admin/users/{userId}/reset-password` | 重置密码，仅管理员 |

新增 ISBN 重复返回 `409 / BOOK_ISBN_EXISTS`；更新时 `totalCount` 小于当前已借量返回 `409`。彻底删除仅适用于没有借阅历史、预约历史、愿望单引用和关联推荐数据的误录书目；日常下架应改用“停止借阅”，保留历史数据。

## 7. AgentAI 图书助手

以下接口需要登录。Agent 的查询工具是只读的；所有写操作只能生成待确认草案，不能由模型直接修改业务数据。馆藏维护方案只向 `ADMIN` 和 `LIBRARIAN` 开放，彻底删除只允许 `ADMIN`。

| 方法 | 路径 | 说明 |
|---|---|---|
| `POST` | `/api/qa/agent/run` | 推荐的同步 Agent 调用入口 |
| `POST` | `/api/qa/agent/stream` | SSE 流式 Agent 调用入口 |
| `GET` | `/api/qa/history?sessionId=` | 获取当前用户会话历史 |
| `DELETE` | `/api/qa/history?sessionId=` | 清空当前用户指定会话或全部历史 |
| `POST` | `/api/qa/catalog/proposals/{token}/actions` | 从馆藏候选方案生成操作草案，仅馆员/管理员 |
| `POST` | `/api/qa/actions/{token}/confirm` | 用户确认并执行 Agent 操作草案 |
| `DELETE` | `/api/qa/actions/{token}` | 取消 Agent 操作草案 |
| `GET` | `/api/qa/book/analyze`、`/background`、`/content`、`/recommend` | 图书分析兼容入口 |
| `GET` | `/api/qa/recommend`、`/chat`、`/chat/stream` | 推荐/聊天兼容入口 |

`POST /api/qa/agent/run` 请求示例：

```json
{
  "question": "推荐一本现在可借的科幻小说，并告诉我位置",
  "sessionId": "session_20260818_001"
}
```

`question` 不能为空且最长 1000 字符；`sessionId` 可选，若提供只能由 8 到 64 位字母、数字、下划线或连字符组成。外部模型不可用时返回 `503`，前端应提示用户稍后重试。

馆藏方案请求示例：

```json
{
  "actionType": "INCREASE_STOCK",
  "query": "Java编程思想",
  "isbn": "9787111213826",
  "quantity": 2,
  "location": "A-03"
}
```

`actionType` 支持 `ADD_BOOK`、`INCREASE_STOCK`、`REDUCE_STOCK`、`DISABLE_BOOK`、`ENABLE_BOOK`、`DELETE_BOOK`。新增书目还需提交 `title`、`author`，可提交出版社、分类、关键词和简介；数量范围为 1 到 1000。服务端会验证查询词和 ISBN 确实来自该方案，客户端不能借令牌操作未展示的书目。

Agent 支持个人数据查询、`prepare_action` 读者业务草案、`propose_catalog_management` 馆藏候选方案，以及 `open_verified_ebook` 合规阅读工具。用户可以输入“打开《红楼梦》第十回”或“继续阅读《西游记》”；未指定章节时恢复当前用户上次进度。工具只接受书名/ISBN 与章节号，服务端重新执行电子资源发布闸门并返回结构化 `navigation`，不会接受或返回任意外部跳转地址。确认接口会重新绑定当前 JWT 用户、重新读取账号状态和最新角色、校验草案有效期及实时库存规则，并将执行记录写入审计日志。减少馆藏不得低于已借副本与已通知预约保留副本之和；停借/恢复不会删除历史数据。

## 8. 合规电子阅读接口

所有接口均需登录。系统只发布权属记录完整且命中服务端固定白名单的古典原文；未获全文许可的馆藏只返回书目详情，不提供正文。

| 方法 | 路径 | 说明 |
|---|---|---|
| `GET` | `/api/books/{isbn}/ebook` | 获取已核验电子资源、来源许可和当前用户阅读进度 |
| `GET` | `/api/books/{isbn}/ebook/chapters/{chapterNumber}` | 从固定中文维基文库 API 获取并安全清洗指定章节 |
| `PUT` | `/api/books/{isbn}/ebook/progress` | 保存当前用户的章节及滚动进度 |
| `POST` | `/api/admin/ebooks/{isbn}/unpublish` | `ADMIN` / `LIBRARIAN` 立即下架电子正文；接口不提供直接重新上架 |

资源元数据响应示例：

```json
{
  "success": true,
  "code": "OK",
  "data": {
    "isbn": "9787020002207",
    "title": "红楼梦",
    "author": "曹雪芹",
    "rightsStatus": "PUBLIC_DOMAIN_VERIFIED",
    "sourceName": "中文维基文库",
    "sourceUrl": "https://zh.wikisource.org/wiki/紅樓夢",
    "licenseName": "CC BY-SA 4.0",
    "licenseUrl": "https://creativecommons.org/licenses/by-sa/4.0/deed.zh-hans",
    "jurisdiction": "全球公版古典原作；数字文本按 CC BY-SA 4.0 使用",
    "chapterCount": 120,
    "contentNotice": "仅展示古典原文；不包含现代出版社的校注、译文、插图、封面或版式。",
    "verifiedAt": "2026-08-19T18:30:00",
    "progress": { "chapterNumber": 1, "scrollPercent": 0, "updatedAt": null }
  }
}
```

章节响应的 `contentHtml` 已在后端使用白名单清洗，前端不得绕过接口直接嵌入第三方 HTML。响应同时包含 `sourcePageUrl`、`licenseName`、`licenseUrl`、`attribution` 和 `modificationNotice`，阅读页必须展示这些字段。

进度请求：

```json
{
  "chapterNumber": 12,
  "scrollPercent": 64
}
```

`chapterNumber` 必须处于该资源已核验章节范围，`scrollPercent` 为 0 至 100。发布闸门同时校验：`PUBLIC_DOMAIN_VERIFIED` 状态、作者逝世超过 100 年、1930 年前发表、固定来源域名与章节规则、许可证、权属依据、内容声明和核验时间。版权清单见 `docs/电子资源版权清单.md`。

## 9. 运维与接口发现

| 路径 | 权限 | 说明 |
|---|---|---|
| `GET /actuator/health` | 公开 | 存活与依赖健康检查 |
| `GET /actuator/info` | 公开 | 应用元信息 |
| `GET /actuator/metrics` | `ADMIN` | Micrometer 指标列表 |
| `GET /swagger-ui.html` | 公开 | Swagger UI |
| `GET /v3/api-docs` | 公开 | OpenAPI JSON |

生产环境不要将 `/actuator/**` 置为公开。需要在网关、反向代理或 Spring Security 层对指标端点继续限制访问。
